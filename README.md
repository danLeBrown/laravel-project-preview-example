## About Laravel

Laravel is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling. Laravel takes the pain out of development by easing common tasks used in many web projects, such as:

- [Simple, fast routing engine](https://laravel.com/docs/routing).
- [Powerful dependency injection container](https://laravel.com/docs/container).
- Multiple back-ends for [session](https://laravel.com/docs/session) and [cache](https://laravel.com/docs/cache) storage.
- Expressive, intuitive [database ORM](https://laravel.com/docs/eloquent).
- Database agnostic [schema migrations](https://laravel.com/docs/migrations).
- [Robust background job processing](https://laravel.com/docs/queues).
- [Real-time event broadcasting](https://laravel.com/docs/broadcasting).

Laravel is accessible, powerful, and provides tools required for large, robust applications.

## Preview example

This project is a minimal API example suitable for preview environments. It uses PostgreSQL, Redis, and an `.env` file. Your preview tool can use it to verify support for a typical Laravel app.

### Running locally

1. Copy `.env.example` to `.env` and set `DB_*` and `REDIS_*` (and run `php artisan key:generate`).
2. Run migrations and seed: `php artisan migrate --force && php artisan db:seed --force`.
3. Start the server: `php artisan serve`.

### Running with Docker Compose

1. Copy `.env.example` to `.env` and run `php artisan key:generate` (or set `APP_KEY`). Set `DB_PASSWORD=secret`, `DB_DATABASE=laravel_project_preview_example`, and `DB_USERNAME=root` to match the postgres service.
2. Start the stack: `docker compose up --build`.
3. In another terminal, run migrations and seed inside the app container: `docker compose exec app php artisan migrate --force && docker compose exec app php artisan db:seed --force`.

The API is available at `http://localhost:8000`.

### API endpoints

| Endpoint | Description |
|----------|-------------|
| `GET /up` | Laravel built-in health (returns 200 when app is booted). |
| `GET /api/health` | JSON health with `status`, `app`, `environment`, and `checks` (database, redis). |
| `GET /api/version` | JSON with `app`, `environment`, `laravel_version`. |
| `GET /api/users/count` | JSON with `count` (number of users). |
